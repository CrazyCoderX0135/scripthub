about scripthub

a home for useful, runnable scripts anyone can pick up and use

ScriptHub is a free collection of scripts for everyday tasks — automating your files, monitoring your system, generating passwords, building games, and more. Every script is copy-paste ready and works right from your terminal with Python, JavaScript, or Shell. No signup, no login, no nonsense.

📋

copy & run

Every script is ready to go. Copy the code, save it, and run it — that's it.

🆓

completely free

No accounts. No paywalls. No ads. Just scripts.

🌍

cross-platform

Scripts work on Windows, Mac, and Linux. The guide covers all three.

📤

community-driven

Anyone can submit a script. Good ones get featured on the homepage.

🔰

beginner friendly

Every script has a difficulty rating and shows what libraries you need to install.

🚀

always growing

New scripts get added regularly. Check the changelog to see what's new.

how to contribute

Have a useful script you built? Submit it using the submit page. We review every submission before it goes live to make sure it's safe, useful, and works. Good scripts get added to the collection — great ones get featured.

Want a script that doesn't exist yet? Head to the request page and tell us what you need.

v2.6 — May 2026
🐛 bug fix patch — script.html final repair
Fixed a remaining truncation in script.html that was causing every script detail page to show "loading…". The file was cut off inside the clearRunner() function — missing its body, closing brace, and the closing </script></body></html> tags. Also removed a spurious extra closing brace inside the iframe message handler (leftover from a previous repair attempt) and added a proper type guard + removeEventListener so the runner can't fire twice or crash on unrelated postMessage events. Service worker bumped to v3.
bug fix
v2.5 — May 2026
🐛 bug fix patch — critical JS repairs
Fixed a cascade of file-truncation bugs that were silently breaking large parts of the site. app.js was cut off before its init calls, which caused the script grid to never render and the count badge to stay stuck on "loading…" — clicking any filter, tag, or difficulty button appeared to do nothing. script.html had a duplicate HTML block injected mid-JavaScript (from an old bad append) plus was truncated inside the iframe runner handler, leaving every script page stuck on "loading…" regardless of which script was opened or how you navigated there. submit.html was missing its entire closing section — the form submission handler, countdown redirect, and closing tags were all absent, which also caused the explore dropdown and theme toggle to silently break (the browser was eating the footer HTML as raw JavaScript). collections.html was cut off mid-function with null bytes appended, also causing a broken page. Service worker bumped to v2 to force all cached visitors to pick up the repaired files.
bug fix
v2.4 — May 2026
✨ contributors page + collection zip downloads + language filter + sort
Added a Contributors page showing live site stats (total scripts, languages, categories, community likes), a hall of fame, contributor cards, and a step-by-step guide for submitting your own script. Collection detail pages now have a "download all (.zip)" button that bundles every script in the pack with a README using JSZip. The browse page gained a language filter row (all / python / js / shell / powershell) and a sort dropdown (default / A→Z / Z→A / most liked / most viewed) that all cooperate with the existing tag, difficulty, and search filters. 👥 contributors added to the explore dropdown on every page.
new feature
v2.3 — May 2026
🔥 trending page + PWA + code theme picker + run in browser + embed
Trending page ranks scripts by views × 1 + likes × 3 with animated fill bars and a recently-viewed heat grid — all tracked locally in your browser. ScriptHub is now installable as a PWA (manifest + service worker with stale-while-revalidate caching). Script pages gained a 🎨 syntax theme picker (6 highlight.js themes), a ▶ run button for JavaScript scripts that executes code in a sandboxed iframe and streams console output, and an embed widget that generates a portable HTML card snippet. View tracking (sh-views-{id}) added site-wide.
new feature pwa
v2.2 — May 2026
💅 professional redesign + tutorial steps + submit UX overhaul
Switched body font to system UI (the single biggest visual improvement — no more toy-website feel). Cards got deeper shadows, tighter hover states, and better typography hierarchy. Every script page now auto-generates a numbered tutorial with copy-able terminal commands, pip install steps, and pro tips from meta.js. The submit form was rebuilt with a live progress bar, per-field character counters, an animated SVG checkmark on success, and a 5-second countdown redirect back to browse. Nav reorganised into primary links + an "explore ▾" dropdown for secondary pages.
redesign new feature
v2.0 — May 2026

Launched with 30 scripts across 5 categories. Added light/dark mode, syntax highlighting, difficulty badges, library requirements, script ratings, copy link button, featured section, random script button, typing animation, and this changelog. Also added the about, request, and guide pages.

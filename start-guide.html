🔰 complete beginner's guide

everything you need to go from zero to running your first script

⬇ step 0 — pick your editor

An editor is the app you use to write and run scripts. Pick one below — the rest of the guide will adjust for your choice.

🖥️
VS Code
Visual Studio Code by Microsoft
⭐ recommended for most people
✓ pros
Colorful syntax highlighting — code is color-coded so it's easier to read
Built-in terminal — run scripts without leaving the editor
Catches errors before you run with red underlines
Auto-complete — suggests code as you type
Line numbers — makes finding errors easy
Used by real developers — skills transfer directly
Free forever
✗ cons
Bigger download (~100 MB)
Requires installing a Python extension separately (one click, easy)
More buttons and menus than IDLE — can feel like a lot at first
🐍
Python IDLE
Comes free with Python
✓ built into Python — nothing extra to install
✓ pros
Already installed — if you have Python, you have IDLE
Simple and clean — almost nothing to figure out
Built specifically for learning Python
Has a built-in Python shell to test one line at a time
Very small — launches in seconds
✗ cons
Basic interface — limited colors and features
No built-in terminal — you run scripts from the menu
No extensions or plugins
Looks old — some people find it discouraging
Not used professionally — you'll have to learn a new tool later

💻 what operating system are you on?
🪟 VS Code on Windows — step by step
1
Install Python
Go to python.org/downloads and click the big yellow "Download Python" button. Run the installer you download.

⚠ Critical: On the very first screen of the installer, check the box that says "Add Python to PATH" before clicking Install Now. If you miss this, your scripts won't run from the terminal.
Important: The "Add Python to PATH" checkbox is at the bottom of the first installer screen. It is NOT checked by default. Don't skip this!
2
Install VS Code
Go to code.visualstudio.com and click "Download for Windows". Run the installer — the defaults are fine, just click Next through everything.
Tip: On the "Select Additional Tasks" screen, check "Add to PATH" and "Add 'Open with Code' to context menu" — these are handy extras.
3
Install the Python extension in VS Code
Open VS Code. On the left sidebar, click the four-square icon (Extensions). In the search bar, type Python. The first result will be "Python" by Microsoft — click Install. This is what makes VS Code understand Python code.
✓ You only need to do this once — after it's installed, VS Code will automatically use it for every .py file you open.
4
Copy a script from ScriptHub
Go to ScriptHub's browse page, pick a script you want to try (start with something from the Beginner's Corner), and click "copy code" on the script page.
Tip: Try password-gen or number-guesser — they're fun and have no extra installs required.
5
Create a new file and paste the code
In VS Code: go to File → New File (or press Ctrl+N). Paste the code with Ctrl+V. Then save it: File → Save As (or Ctrl+Shift+S). Navigate to your Desktop, and name the file something like myscript.py.
Critical: the file MUST end in .py — if you accidentally save it as "myscript.py.txt" it won't work. VS Code will warn you if this happens.
6
Open the built-in terminal
In VS Code: go to View → Terminal, or press Ctrl+` (that's the backtick key, top-left of your keyboard). A panel will open at the bottom — this is your terminal. It should say something like PS C:\Users\YourName\Desktop> if you saved to the Desktop.
Tip: If the terminal is showing a different folder, type: cd %USERPROFILE%\Desktop and press Enter to navigate to your Desktop.
7
Run the script!
In the terminal, type the following and press Enter: python myscript.py Replace myscript with whatever you named your file. The script will start running right there in the terminal.
🎉 That's it! If you see output in the terminal, your script is working. If the script asks for input, just type your answer and press Enter.
🍎 VS Code on Mac — step by step
1
Check if Python is installed
Press Cmd+Space, type Terminal, press Enter. In the terminal, type: python3 --version If you see a version number (like Python 3.12.0), you're good. If you see "command not found," go to python.org/downloads and download the Mac installer.
2
Install VS Code
Go to code.visualstudio.com and click "Download for Mac". It downloads a .zip — double-click it to unzip, then drag Visual Studio Code.app into your Applications folder.
Tip: Open VS Code, then open the Command Palette with Cmd+Shift+P, type "shell command" and select "Install 'code' command in PATH". This lets you open VS Code from your terminal later.
3
Install the Python extension
In VS Code, click the four-square icon on the left sidebar (Extensions). Search for Python and install the one by Microsoft. VS Code may also prompt you at the bottom-right to install it when you open a .py file — you can click that prompt too.
4
Copy a script from ScriptHub
Browse Beginner's Corner and pick a script. Click "copy code" on the script page.
Good starters: password-gen, weather, or number-guesser.
5
Create a new file and paste the code
In VS Code: File → New File (or Cmd+N). Paste with Cmd+V. Then File → Save As (Cmd+Shift+S). In the save dialog, navigate to your Desktop and name the file myscript.py.
Important: Make sure the filename ends with .py — not .txt or .py.txt. VS Code will highlight Python code once you save with the .py extension.
6
Open the built-in terminal
Go to View → Terminal in VS Code, or press Ctrl+`. A panel opens at the bottom. Navigate to your Desktop: cd ~/Desktop Press Enter.
7
Run the script!
Type this and press Enter: python3 myscript.py
🎉 You're running a script! On Mac, use python3 instead of python — it's the same thing, just the Mac version.
🐧 VS Code on Linux — step by step
1
Install Python (if not already)
Open a terminal (Ctrl+Alt+T) and run: sudo apt install python3 python3-pip On Fedora/RHEL use dnf instead of apt.
2
Install VS Code
Go to code.visualstudio.com, download the .deb (for Ubuntu/Debian) or .rpm (for Fedora) package and install it. Or install via snap: sudo snap install --classic code
3
Install the Python extension, copy script, paste, save, and run
Same as Mac — install the Python extension via the Extensions panel, copy a script from ScriptHub, paste into a new file, save as myscript.py, open the terminal (Ctrl+`), and run: python3 myscript.py
🪟 Python IDLE on Windows — step by step
1
Install Python (IDLE comes included!)
Go to python.org/downloads and download the Windows installer. Run it.

⚠ Critical: Check "Add Python to PATH" at the bottom of the first screen before installing. IDLE is automatically installed along with Python — you don't need to install it separately.
✓ IDLE is free and comes with Python. You get both in one installer — no extra steps needed.
2
Open IDLE
Press the Windows key, type IDLE, and press Enter. You'll see the Python Shell window — this is the IDLE interface. It shows a >>> prompt where you can type Python one line at a time.
Tip: The Shell window is for testing quick commands. For running a full script file, you need to create a new file (next step).
3
Create a new script file
In the IDLE Shell window, go to File → New File (or press Ctrl+N). A blank editor window opens — this is separate from the Shell. This is where you paste your script.
4
Copy a script from ScriptHub and paste it
Go to Beginner's Corner, pick a script, and click "copy code". Go back to your IDLE editor window and paste with Ctrl+V.
5
Save the file as a .py file
Go to File → Save As (or Ctrl+Shift+S). Navigate to your Desktop. In the File name box, type something like myscript.py. Make sure "Save as type" says Python files (*.py) or All Files. Click Save.
Important: If "Save as type" is set to "Text Documents," change it to "All Files" and make sure your filename ends with .py. Otherwise Windows will save it as .py.txt and it won't work.
6
Run the script!
In your IDLE editor window, go to Run → Run Module — or just press F5. The Shell window will pop to the front and your script will start running there.
🎉 That's all it takes with IDLE! No terminal commands needed — just F5 to run. Output (and any input prompts) will appear in the Shell window.
🍎 Python IDLE on Mac — step by step
1
Install Python from python.org
Mac comes with a very old version of Python that doesn't include IDLE properly. Download the latest from python.org/downloads and run the installer. IDLE is included.
Don't use the Mac's built-in Python — it's outdated. Always install the fresh one from python.org to get IDLE and the newest Python features.
2
Open IDLE
Press Cmd+Space, type IDLE, and press Enter. If multiple results appear, pick the one with the highest Python version number. The Shell window will open.
Can't find IDLE? Open Finder → Applications → Python 3.x folder → IDLE.app
3
Create a new file, paste, save, and run
In IDLE: File → New File (Cmd+N). Copy a script from ScriptHub and paste with Cmd+V. Save with File → Save As (Cmd+Shift+S) — navigate to Desktop, name it myscript.py and click Save.

To run: press F5, or go to Run → Run Module. Output appears in the Shell window.
✓ On Mac, IDLE works exactly the same as on Windows — File → New, paste, save as .py, F5 to run.
🐧 Python IDLE on Linux — step by step
1
Install Python and IDLE
Open a terminal (Ctrl+Alt+T) and run: sudo apt install python3 idle3
2
Open IDLE
Search your app launcher for IDLE, or run in terminal: idle3
3
Create a file, paste, save, run
File → New File → paste your script → File → Save As → save as myscript.py → press F5 to run.
📦 installing extra libraries

Some scripts on ScriptHub need extra libraries (like Pillow or psutil). The script page will tell you what's needed in a yellow "requires" box. Here's how to install them.

!
Open a terminal (command prompt)
Windows: Press Windows+R, type cmd, press Enter.
Mac/Linux: Open Terminal from Spotlight or your app launcher.
!
Run the install command
Type the following and replace libraryname with the library you need:
Windows:
pip install libraryname
Mac / Linux:
pip3 install libraryname For example, to install Pillow: pip install Pillow. You only need to do this once per library.
✓ Already listed for you — every script on ScriptHub that needs extra libraries shows them in a yellow box. Just copy and paste the install command shown there.
🔴 common errors and how to fix them

Something went wrong? Find your error below.

ModuleNotFoundError: No module named 'X'
What it means: The script needs a library that isn't installed yet.
Fix: Run pip install X (Windows) or pip3 install X (Mac/Linux) in your terminal, replacing X with the library name. Then try running the script again.
python: command not found / 'python' is not recognized
What it means: Python isn't installed, or wasn't added to your PATH during installation.
Fix (Windows): Uninstall Python and reinstall it from python.org — this time, check the "Add Python to PATH" box on the first screen.
Fix (Mac): Try using python3 instead of python.
SyntaxError: invalid syntax
What it means: There's a typo or formatting problem in the code. This usually happens when pasting went wrong — for example, smart quotes (" ") instead of straight quotes (" ").
Fix: Delete the script and copy it fresh from ScriptHub using the "copy code" button (don't type it manually). Make sure to paste into a plain text file, not Word.
FileNotFoundError: [Errno 2] No such file or directory
What it means: The script is looking for a file or folder that doesn't exist at the path you gave it.
Fix: Double-check the path you typed. On Windows, use backslashes: C:\Users\YourName\Desktop. On Mac/Linux, use forward slashes: /Users/yourname/Desktop. Make sure the file actually exists at that location.
IndentationError: unexpected indent
What it means: The script has a spacing/tab problem. This usually means something went wrong when pasting — extra spaces were added or removed.
Fix: Copy the script fresh from ScriptHub using the "copy code" button. Do not manually re-type any indentation (spaces at the start of lines).
PermissionError: [Errno 13] Permission denied
What it means: The script tried to access a file or folder it doesn't have permission to use.
Fix (Windows): Right-click Command Prompt → "Run as administrator" and try again.
Fix (Mac/Linux): Prefix the command with sudo: sudo python3 myscript.py
KeyboardInterrupt (or nothing happening — script seems stuck)
What it means: The script is waiting for input, running a loop, or monitoring something continuously.
Fix: If the script is supposed to run forever (like a monitor or stopwatch), press Ctrl+C to stop it. If it's waiting for input, just type your answer and press Enter.
💡 tips to make your life easier
⬆️

Use the arrow keys

In the terminal, press the Up arrow key to repeat your last command. No need to retype it every time.

⌨️

Tab completion

Start typing a filename in the terminal and press Tab — it will autocomplete the name for you so you don't have to type every letter.

📁

Keep scripts on your Desktop

Save all your .py files to the Desktop. That way, cd Desktop always puts you in the right place and you can always find them.

🔰

Start with beginner scripts

Scripts marked "beginner" on ScriptHub have no extra installs — they just work. Perfect for your first tries.

🔎

Read the error message

Python errors always tell you exactly what went wrong and which line the problem is on. Read the last line of the error first — it's usually the most useful part.

🌐

Google is your friend

Copy the exact error message and paste it into Google. Someone has almost certainly had the same problem and posted a solution.

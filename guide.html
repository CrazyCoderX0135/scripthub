how to use scripts

pick your operating system below to get started

tip: Python scripts end in .py — they're just text files with code inside. You run them from a window called the "terminal" or "command prompt".
1

install Python

Go to python.org/downloads and download the latest version. Run the installer — make sure to check "Add Python to PATH" before clicking install.

2

copy the script

Find a script on ScriptHub, click it, and hit the copy code button.

3

save it as a .py file

Open Notepad, paste the code, then go to File → Save As. Name your file something like myscript.py and make sure to set "Save as type" to All Files so it doesn't add .txt to the end.

example: save to your Desktop as myscript.py
4

open the terminal

Press Windows + R, type cmd, and hit Enter. A black window will open — that's your terminal.

5

navigate to your file

Type the following to go to your Desktop (or wherever you saved it):

cd %USERPROFILE%\Desktop
6

run the script

Type this and hit Enter (replace myscript.py with your actual filename):

python myscript.py
note: some scripts need extra libraries. if you see an error like "ModuleNotFoundError: No module named X", run pip install X first.
tip: Macs come with a built-in terminal app. Python 3 may already be installed — we'll check in step 1.
1

check if Python is installed

Open Terminal (press Cmd + Space, type "Terminal", hit Enter). Then type:

python3 --version

If you see a version number, you're good. If not, go to python.org/downloads and install it.

2

copy the script

Find a script on ScriptHub, click it, and hit the copy code button.

3

save it as a .py file

Open TextEdit, paste the code. Go to Format → Make Plain Text. Then File → Save, name it myscript.py and save it to your Desktop.

tip: You can also use VS Code or any code editor — much easier than TextEdit.
4

navigate to your file in Terminal

In your Terminal window, type:

cd ~/Desktop
5

run the script

Type this and hit Enter:

python3 myscript.py
note: if you get a "ModuleNotFoundError", install the missing library with pip3 install libraryname.
tip: Python 3 is usually pre-installed on Linux. Let's verify and get you running.
1

check Python

Open a terminal and run:

python3 --version

If it's not installed, run:

sudo apt install python3
2

copy and save the script

Copy the code from ScriptHub, then create a file with nano or any editor:

nano myscript.py

Paste the code, then press Ctrl+X → Y → Enter to save.

3

run the script

python3 myscript.py
note: missing a library? Install it with pip3 install libraryname.

common questions

it says "python is not recognized"

Python isn't added to your PATH. Re-run the Python installer and check the "Add Python to PATH" box, or download it from python.org.

i get a "ModuleNotFoundError"

The script needs an extra library. Install it by running pip install modulename (Windows) or pip3 install modulename (Mac/Linux) in your terminal.

nothing happens when i run it

Make sure you're in the same folder as the file. Use cd to navigate there first, then try running it again.

what editor should i use to write scripts?

We recommend VS Code — it's free, works on all platforms, and makes writing and saving .py files super easy.

how to run a script

follow the steps for your operating system — takes about 5 minutes the first time

1

copy the script

On any script page, click the copy code button in the top right of the code box. The whole script is now on your clipboard.

2

open Notepad and paste

Press Windows key, type Notepad, and open it. Then press Ctrl + V to paste the code.

3

save it as a .py file

Go to File → Save As. At the bottom where it says "Save as type", change it to All Files. Then name your file something like myscript.py and save it to your Desktop.

important: if you skip changing "Save as type" to All Files, Windows will save it as myscript.py.txt and it won't work.
4

install Python (first time only)

Go to python.org/downloads and download Python. Run the installer and check the box that says "Add Python to PATH" before clicking Install.

already installed? skip this step.
5

open Command Prompt

Press Windows key + R, type cmd, and press Enter. A black window will pop up — that's the command prompt.

6

go to your Desktop

Type this and press Enter:

cd %USERPROFILE%\Desktop
7

run the script!

Type this (swap in your actual filename) and press Enter:

python myscript.py

The script will start running and ask you for any input it needs. That's it — you're done! 🎉

error: ModuleNotFoundError? A library is missing. Run pip install libraryname (replace libraryname with whatever it says), then try again.
1

copy the script

On any script page, click the copy code button. The whole script is now on your clipboard.

2

open Terminal

Press Cmd + Space, type Terminal, and press Enter to open it.

3

check if Python is installed

Type this and press Enter:

python3 --version

If you see a version number like Python 3.x.x you're good. If not, go to python.org/downloads and install it.

4

create and save the script

In Terminal, type this to create a new file on your Desktop:

nano ~/Desktop/myscript.py

A text editor opens inside Terminal. Press Cmd + V to paste your code. Then press Ctrl + X, then Y, then Enter to save and exit.

5

run the script!

Type this and press Enter:

python3 ~/Desktop/myscript.py

The script will run and ask you for any input it needs. 🎉

something went wrong?

"python is not recognized as a command"

Python isn't set up in your PATH. Re-run the Python installer from python.org and make sure to check "Add Python to PATH".

"ModuleNotFoundError: No module named X"

The script needs a library that isn't installed. Run pip install X (Windows) or pip3 install X (Mac/Linux) where X is the name from the error message.

the script opened and closed instantly

You probably double-clicked the .py file instead of running it from the terminal. Always run scripts using the terminal with the python myscript.py command.

i saved it but it says .py.txt

When saving in Notepad, you need to change "Save as type" to All Files first. Otherwise Windows adds .txt automatically. Rename the file and remove the .txt part.

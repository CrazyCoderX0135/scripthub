how to run a script

pick your operating system

1

copy the script

Click the copy code button on any script page.

2

open Notepad and paste

Press Windows key, type Notepad, open it, press Ctrl+V.

3

save as a .py file

File → Save As → change "Save as type" to All Files → name it myscript.py → save to Desktop.

important: skip this step and it saves as .py.txt and won't work.
4

install Python (first time only)

Go to python.org/downloads and install. Check "Add Python to PATH" during install.

5

open Command Prompt

Press Windows+R, type cmd, press Enter.

6

navigate to Desktop

cd %USERPROFILE%\Desktop
7

run it! 🎉

python myscript.py
ModuleNotFoundError? Run pip install libraryname then try again.

how to run a script

pick your operating system

1

copy the script

Click copy code on any script page.

2

open Notepad and paste

Windows key → type Notepad → open → Ctrl+V

3

save as .py

File → Save As → "Save as type" = All Files → name it myscript.py → save to Desktop.

important: must change "Save as type" to All Files or it saves as .txt.
4

install Python

python.org/downloads — check "Add Python to PATH".

5

run it

Windows+R → cmd → Enter, then:

cd %USERPROFILE%\Desktop
python myscript.py
ModuleNotFoundError? Run pip install X
1

copy the script

Click copy code on any script page.

2

open Terminal

Cmd+Space → Terminal → Enter.

3

check Python

python3 --version

No version? Download from python.org.

4

in VS Code (easiest)

Open VS Code → new file → paste code → Cmd+Shift+S (Save As) → navigate to Desktop → name it myscript.py → Save.

5

run it

cd ~/Desktop
python3 myscript.py
ModuleNotFoundError? Run pip3 install X
1

copy + open terminal

Copy the script, press Ctrl+Alt+T.

2

create the file

nano ~/Desktop/myscript.py

Paste, then Ctrl+X → Y → Enter.

3

run it

python3 ~/Desktop/myscript.py

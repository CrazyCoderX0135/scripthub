how to run a script

pick your operating system

1

copy the script

Click the copy code button on any script page.

2

open Notepad and paste

Press Windows key, type Notepad, open it, then press Ctrl + V.

3

save as a .py file

File → Save As. Change "Save as type" to All Files. Name it myscript.py and save to your Desktop.

important: if you don't change "Save as type" to All Files, it'll save as .py.txt and won't work.
4

install Python (first time only)

Go to python.org/downloads, install it, and check "Add Python to PATH" during install.

5

open Command Prompt

Press Windows + R, type cmd, press Enter.

6

go to your Desktop

cd %USERPROFILE%\Desktop
7

run it! 🎉

python myscript.py
